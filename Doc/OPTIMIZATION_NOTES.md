## 🔄 部分完成的优化点

### 优化点 #1：地点从健康记录同步
**状态**：🔄 需要进一步研究  
**复杂度**：⭐⭐⭐⭐⭐ 高

**技术挑战**：
1. **GPS 数据获取**：需要从 HKWorkout 获取 GPS 路线数据（HKWorkoutRoute）
2. **反向地理编码**：需要使用 CoreLocation 的 CLGeocoder 将坐标转换为地址
3. **权限管理**：需要额外的位置权限
4. **性能考虑**：反向地理编码是异步操作，会增加导入时间
5. **准确性问题**：GPS 数据可能不准确，特别是室内训练

**实施建议**：
```swift
// 伪代码示例
func extractLocation(from workout: HKWorkout) async -> String? {
    // 1. 获取 workout route
    guard let route = try? await fetchWorkoutRoute(for: workout) else {
        return nil
    }
    
    // 2. 获取起始位置
    guard let startLocation = route.locations.first else {
        return nil
    }
    
    // 3. 反向地理编码
    let geocoder = CLGeocoder()
    guard let placemark = try? await geocoder.reverseGeocodeLocation(startLocation).first else {
        return nil
    }
    
    // 4. 提取地点名称
    return placemark.name ?? placemark.locality
}
```

**替代方案**：
- ✅ 使用预设标签快速选择常用地点
- ✅ 使用历史记录的智能建议
- ⏳ 未来版本可以考虑实现完整的地点同步功能

**决策**：
由于技术复杂度高、需要额外权限、可能影响用户体验，建议：
1. 当前版本使用预设标签和智能建议
2. 在用户反馈中收集对此功能的需求强度
3. 如果需求强烈，在后续版本中实现
