## 📱 测试步骤

### 步骤 1：运行应用

1. 在 Xcode 中按 **`Cmd + R`** 运行应用
2. 应该看到一个测试界面，标题为 "BalletDaily - Phase 0: 配置测试"
3. 界面中间有一个心形图标（灰色）

### 步骤 2：请求 HealthKit 授权

1. **点击蓝色按钮 "请求 HealthKit 授权"**
2. **应该弹出系统权限对话框**，显示：
   ```
   "BalletDaily" 想要访问您的健康数据
   
   需要访问您的健康数据以记录芭蕾课程的运动指标
   
   [不允许]  [好]
   ```

3. **点击 "好"** 允许访问

4. 对话框会显示具体的数据类型选择：
   - 心率
   - 活动能量
   - 步数
   - 距离
   - 体能训练

5. **确保所有数据类型都是 "允许"**（绿色勾选）

6. **点击右上角 "允许"**

### 步骤 3：验证授权成功

授权成功后，界面应该显示：
- ❤️ 心形图标变为**红色填充**
- ✅ 文字变为 "HealthKit 已授权"
- 绿色按钮变为可点击状态

### 步骤 4：测试读取数据

1. **点击绿色按钮 "测试读取训练记录"**
2. **打开 Xcode 底部的控制台**（如果没显示，按 `Cmd + Shift + Y`）
3. **查看控制台输出**

#### 预期输出（情况 A）：有训练记录
```
✅ HealthKit 可用
✅ HealthKit 授权成功
✅ 找到 3 条训练记录
  - 舞蹈: 60.0 分钟
  - 瑜伽: 45.0 分钟
  - 步行: 30.0 分钟
```

#### 预期输出（情况 B）：无训练记录
```
✅ HealthKit 可用
✅ HealthKit 授权成功
📝 最近 7 天没有训练记录
```

## 🆘 常见问题排查

### Q1: 点击授权按钮后应用崩溃
**原因**：隐私权限描述缺失

**解决**：
1. 检查 Info 标签中是否有 `NSHealthShareUsageDescription`
2. 检查 Info 标签中是否有 `NSHealthUpdateUsageDescription`
3. 两个描述都必须有值（不能为空）

### Q2: 没有弹出权限对话框
**可能原因**：
1. 已经授权过了（心形图标应该已经是红色）
2. HealthKit Capability 没有正确添加

**解决**：
1. 检查 Signing & Capabilities 中是否有 HealthKit
2. 尝试删除应用重新安装：
   - 在模拟器中长按应用图标 → 删除
   - 重新运行（Cmd + R）

### Q3: 控制台显示 "HealthKit 在此设备上不可用"
**原因**：模拟器版本问题

**解决**：
1. 切换到更新的模拟器（如 iPhone 15）
2. 或在真机上测试

### Q4: 授权成功但测试读取数据时崩溃或无输出
**原因**：正常情况（模拟器通常没有健康数据）

**验证**：
1. 检查控制台是否显示 "✅ HealthKit 授权成功"
2. 如果显示了这个，说明配置正确
3. 无训练记录是正常的

### Q5: 编译错误 "Cannot find 'HealthKitManager' in scope"
**原因**：新文件没有被 Xcode 识别

**解决**：
1. 在 Xcode 左侧文件导航器中找到 `Services` 文件夹
2. 检查 `HealthKitManager.swift` 文件是否在项目中
3. 如果文件不在，需要手动添加：
   - 右键 `Services` 文件夹
   - `Add Files to "BalletDaily"`
   - 选择 `HealthKitManager.swift`
   - 确保勾选 "BalletDaily" Target
