# UI 参考资料

## 📁 文件夹说明

这个文件夹存放 BalletDaily 项目的 UI 设计参考资料。

## 📸 参考图片

### 习惯追踪 UI 参考
**来源**：用户提供的习惯追踪应用截图  
**参考时间**：2026年1月1日

**包含元素**：
1. 年度统计徽章和数字
2. 全年热力日历（类似 GitHub 贡献图）
3. 活动分类统计卡片
4. 详细的数据指标（坚持天数、平均时长等）

**学习要点**：
- ✅ 年度视图的热力图展示方式
- ✅ 统计数据的多维度展示
- ✅ 卡片式布局的信息组织
- ✅ 日历视图的交互设计

**改进方向**：
- 🎨 更柔和的配色（芭蕾粉 vs 鲜艳蓝）
- 📊 弱化绝对数字，强调趋势
- 🎭 去除游戏化元素（徽章等）
- 🌸 增加留白，提升优雅感
- ✨ 优化文案，减少压力感

详细的对比分析和改进方案，请参考 [UI_DESIGN.md](../UI_DESIGN.md)

## 🎨 使用说明

在设计和开发过程中：
1. **参考优点** - 学习其信息架构和布局方式
2. **避免缺点** - 注意颜色、措辞、游戏化等问题
3. **符合原则** - 始终遵循"极简输入、长期趋势、安静不打扰"
