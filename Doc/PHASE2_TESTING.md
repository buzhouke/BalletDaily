# Phase 2: HealthKit 集成 - 测试指南

## 📋 测试概述

Phase 2 实现了 HealthKit 集成功能，包括：
- ✅ 查询训练记录（Workout）
- ✅ 获取心率统计和时间序列数据
- ✅ 自动识别和导入芭蕾课程
- ✅ 健康数据同步到 Core Data

---

## 🎯 测试前准备

### 1. 确保 HealthKit 权限配置正确

检查 `Info.plist` 或 `BalletDaily.entitlements` 是否包含：
- `NSHealthShareUsageDescription`: "BalletDaily 需要访问您的健康数据以记录芭蕾课程和健康指标"
- HealthKit Capability 已启用

### 2. 准备测试数据

在 iPhone 的「健康」App 中手动添加一些训练记录：

**方法 1: 使用健康 App**
1. 打开「健康」App
2. 点击「浏览」→「活动」→「体能训练」
3. 点击右上角「添加数据」
4. 选择「舞蹈」类型
5. 设置日期、时间、时长
6. 保存

**方法 2: 使用 Apple Watch**
- 在 Apple Watch 上开始一个「舞蹈」训练
- 训练结束后数据会自动同步到健康 App

**建议测试数据**：
- 至少添加 2-3 条舞蹈训练记录
- 时长建议：30 分钟 - 90 分钟
- 日期：最近 7 天内

## 🔍 数据验证

### Core Data 实体检查

**BalletSession**：
- `healthKitWorkoutUUID`: 应该包含 UUID 字符串
- `isManualEntry`: 导入的课程应为 `false`
- `healthMetrics`: 应该有关联的 HealthMetrics 对象

**HealthMetrics**：
- `avgHeartRate`, `minHeartRate`, `maxHeartRate`: 应该有值（如果有心率数据）
- `activeEnergy`: 应该有值
- `heartRateData`: 应该包含序列化的 JSON 数据（如果有心率样本）
- `syncedAt`: 应该是最近的时间戳
- `session`: 应该正确关联到 BalletSession

---

## ⚠️ 常见问题

### 1. 权限对话框不弹出
**原因**：可能已经授权过或拒绝过
**解决**：
- 设置 → 隐私与安全 → 健康 → BalletDaily
- 重新设置权限
- 或删除应用重新安装

### 2. 读取不到训练记录
**检查**：
- 健康 App 中是否有数据
- 是否已授权读取「体能训练」权限
- 数据是否在查询的日期范围内

### 3. 没有心率数据
**说明**：
- 手动添加的训练记录通常没有心率数据
- 需要使用 Apple Watch 记录训练才会有心率
- 这是正常现象，不影响其他功能

### 4. 导入后没有创建课程
**检查**：
- 查看控制台错误信息
- 确认 Core Data 保存成功
- 检查是否有重复导入的过滤
