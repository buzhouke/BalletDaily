# BalletDaily UI 设计方案

## 📸 参考资料

**参考图片位置**：`Doc/UI_References/`

参考的习惯追踪 UI 包含以下元素：
- 年度日历热力图
- 统计数据展示（天数、时长）
- 活动分类统计
- 徽章系统

---

## 🎨 设计理念

### 核心原则
基于项目的三大核心价值：
1. **极简输入** - UI 不应增加用户负担
2. **长期趋势可视化** - 展示有意义的趋势，而非绝对数字
3. **安静不打扰** - 柔和、优雅、无压力感

### 芭蕾美学
- ✨ **优雅** - 如同芭蕾舞姿般流畅
- 🎭 **克制** - 适度的装饰，不喧宾夺主
- 🌸 **柔和** - 温柔的配色，舒适的视觉
- 📐 **平衡** - 信息与留白的完美比例

---

## 🆚 参考 UI 分析

### ✅ 优点
1. **年度视图直观** - 热力图清晰展示全年数据
2. **统计维度丰富** - 多角度展示用户习惯
3. **活动分类清晰** - 不同活动独立统计
4. **视觉层次分明** - 卡片式布局组织良好

### 🔄 可改进之处（基于我们的原则）

| 参考 UI 特点 | 问题 | 我们的改进 |
|-------------|------|-----------|
| 鲜艳的蓝色 | 视觉刺激强，不够"安静" | 柔和的芭蕾粉 + 淡雅灰蓝 |
| 大量数字 | 容易产生压力感 | 弱化绝对数字，强调趋势 |
| 徽章系统 | 过度游戏化 | 移除徽章，用优雅的图标 |
| 密集的信息 | 视觉疲劳 | 增加留白，分屏展示 |
| "投入最多" 等指标 | 可能产生焦虑 | 改为"你的节奏"等中性表达 |
| 多个活动混合 | 复杂度高 | 专注芭蕾，简化场景 |

## 🎨 BalletDaily 配色方案

### 主色调（优雅的芭蕾风格）

```swift
// 主色 - 芭蕾粉（降低饱和度）
Primary: #D4A5A5 (粉灰色，优雅不刺眼)

// 次要色 - 柔和灰蓝
Secondary: #A8B5C7 (灰蓝，专业感)

// 背景色
Background: #F9F6F4 (米白色，温暖柔和)

// 文字颜色
Text Primary: #3D3D3D (深灰，不用纯黑)
Text Secondary: #8A8A8A (中灰)
Text Hint: #C4C4C4 (浅灰)

// 强调色
Accent: #B8A398 (杏色，温暖点缀)
Success: #C4D4C4 (浅绿，成就感但不刺眼)

// 趋势图渐变（热力图）
Gradient:
  - Level 0: #F5F5F5 (几乎透明)
  - Level 1: #E8D8D8 (极浅粉)
  - Level 2: #D4B8B8 (浅粉)
  - Level 3: #C49898 (中粉)
  - Level 4: #B47878 (深粉)
```

#### 设计细节

**统计卡片样式**：
```swift
struct StatCard {
    // 圆角：16pt（柔和）
    // 阴影：极浅，y偏移2pt
    // 内边距：20pt
    // 卡片间距：16pt
```

**热力日历**：

## 🎭 动画和交互

### 动画原则
- **柔和流畅** - 如同芭蕾动作般优雅
- **不过度** - 避免眼花缭乱
- **有意义** - 每个动画都有目的

### 标准动画参数
```swift
enum Animation {
    // 默认动画（大部分交互）
    static let standard = Animation.easeInOut(duration: 0.3)
    
    // 快速动画（按钮点击）
    static let quick = Animation.easeOut(duration: 0.15)
    
    // 慢速动画（页面切换）
    static let slow = Animation.easeInOut(duration: 0.5)
    
    // 弹性动画（添加元素）
    static let spring = Animation.spring(
        response: 0.5,
        dampingFraction: 0.7,
        blendDuration: 0
    )
}
```

### 交互反馈
- **按钮点击** - 轻微缩放（0.95）
- **卡片点击** - 淡入淡出（opacity）
- **滑动删除** - 平滑偏移（offset）
- **下拉刷新** - 优雅的旋转动画
