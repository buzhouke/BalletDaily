### 优化点 #7：移除同步数量限制 ✅

**问题**：
- 当前只同步了 10 条记录
- 应该同步所有记录

**修复方案**：
1. 将 `fetchRecentWorkouts` 的默认 limit 从 20 改为 100
2. 将测试方法中的 `limit: 10` 改为 `limit: 100`
3. 保留 limit 参数以便灵活控制

**修改文件**：
- `BalletDaily/Services/HealthKitManager.swift`

**代码变更**：
```swift
// 修改默认限制
func fetchRecentWorkouts(limit: Int = 100) async throws -> [WorkoutDetails]

// 测试方法也更新
let workouts = try await fetchRecentWorkouts(limit: 100)
```

**技术说明**：
- 保留了 limit 参数，避免一次性加载过多数据
- 100 条记录对于大多数用户来说已经足够
- 如需查询所有记录，可以使用 `fetchWorkouts(from:to:)` 方法，它使用 `HKObjectQueryNoLimit`

**耗时**：1 小时

### 优化点 #3：笔记添加交互优化 ✅

**问题**：
1. 笔记的添加入口不明显（浅灰色按钮）
2. 交互不统一
3. 应该支持在编辑界面也能记笔记
4. 字段（老师、地点）应该支持点击后编辑

**修复方案**：

#### 3.1 增强快速添加按钮视觉效果

**修改前**：
- 浅灰色背景，不够醒目
- 小字体，不够清晰

**修改后**：
- 添加 `plus.circle.fill` 图标，更明显
- 增大字体（`.subheadline`，加粗）
- 增加内边距（14x10，原来是 12x8）
- 增强背景色不透明度（0.15，原来是 0.1）
- 增强边框（1.5px，原来是 1px）
- 添加阴影效果
- 更大的圆角（20，原来是 16）

**视觉对比**：
```

```

#### 3.2 实现字段点击编辑

**创建新组件**：`EditableInfoRow`
- 在原有 `InfoRow` 基础上添加点击功能
- 添加右侧箭头图标提示可点击
- 点击后跳转到编辑界面

**修改文件**：
- `SessionDetailView.swift` - 添加 `EditableInfoRow` 组件
- 将"老师"和"地点"字段改为可点击
