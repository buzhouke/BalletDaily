## 📊 技术实现

### MVVM 架构

**ViewModel 职责**：
- 数据加载和管理
- 业务逻辑处理
- 状态管理（加载中、错误）
- 搜索和筛选逻辑

**View 职责**：
- UI 展示
- 用户交互
- 状态监听和更新

### 数据绑定

使用 SwiftUI 的声明式语法：
- `@Published` 属性自动更新 UI
- `@State` 管理本地状态
- `@StateObject` 持有 ViewModel
- `@Environment` 注入依赖

### 异步操作

- 使用 `async/await` 处理数据操作
- `Task {}` 包装异步调用
- 主线程更新 UI（`@MainActor`）
